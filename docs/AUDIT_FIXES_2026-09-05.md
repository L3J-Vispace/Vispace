# 전체 코드 점검 후속 수정

사용자가 제공한 「Vispace 전체 코드 점검 보고서」의 기준 커밋 `94e744cc64b3b464aa522cc4a25dc20be328eb57`을 출발점으로 F01–F07을 재검토했다. 이 작업은 기존 기능의 경계 조건과 동시 실행 결함을 수정한다. G01–G08의 구현 범위, 단일 ARSession 구조, 원본 카메라 영상의 비저장 정책을 유지한다.

관계의 부정 질문에도 답변은 저장된 사실의 방향을 명시한다. 예를 들어 “테이블 위에 컵이 없지?”에 실제 `cup on table` 기록이 있으면 “확정된 기록상 ‘cup’은(는) ‘table’ 위에 있어요.”라고 표시한다. 관계 기록이 없을 때 부재를 만들어 내지 않는다. 자유로운 문장 전체를 지원하는 언어 모델 기능은 추가하지 않는다.

## 검증 기록

2026년 9월 5일 23:46 KST, Xcode 26.6(17F113)·iOS 26.5 SDK·macOS 26.6.2에서 `Scripts/verify-ios.sh`를 새 빌드 디렉터리로 실행해 종료 코드 0을 확인했다.

- Core: XCTest 343개와 Swift Testing 9개, 총 **352개 통과**.
- iPhone 17 시뮬레이터: **507개 통과, 2개 제외, 실패 0개**. 세 번째·네 번째 방문의 실제 컨트롤러/정렬 저장소 시험도 통과했다.
- 제외 항목: `PlaceVisualEvidenceTests.testRealCameraBufferProducesRevisionPinnedVisionFeatures`, `SpatialStorageDirectoryTests.testEffectiveFileProtectionOnPhysicalDevice`.
- Debug·Release 시뮬레이터 빌드, 서명 없는 기기 Archive, Analyze 통과.
- XcodeGen 재생성, 모델 해시·번들, 한국어 리소스, 개인정보 선언과 Release 디버그 우회 문자열 검사 통과.
- Windows와 Mac의 Swift 162개 파일을 LF 정규화 후 SHA-256으로 대조해 일치했다. 최종 소스 동결 뒤 실행한 결과다.
- 일반 Release 실행: 테스트 인자 없이 시작해 초기 한국어 안내 화면을 확인했다. 10초 후 프로세스가 유지됐고 새 Vispace 크래시 보고서는 0개였다.

실행 결과 경로는 Mac의 `TestResults/verification-primary.pfnaNR/Tests.xcresult`다. 기능별 선행 iOS 검사는 167개 통과·1개 제외·실패 0개였다. 관계 질문의 추가 시험은 수정 전 실패를 확인한 뒤 수정 후 통과했다. 개발 중 두 테스트의 타입/도우미 연결 컴파일 오류를 수정했으며, 그 실패 실행을 위 최종 결과에 합산하지 않았다. 게시된 최종 커밋의 GitHub CI 결과는 PR에 기록한다.

## 영향과 되돌리기

영향 범위는 안내·배치, 관측 저장과 복구, 공간 정합, 앵커 최신성, 관계 질문이다. 공간 판정과 저장 직렬화가 포함되므로 변경 위험도는 높음으로 관리한다. 기존 저장 문서의 스키마를 변경하거나 사용자 기록을 삭제하지 않는다. 같은 지도의 저장 콜백이 지연되면 후속 저장도 순서대로 대기한다. 대기 중인 요청의 취소와 다른 지도 작업은 별도로 진행할 수 있다.

수정 커밋은 문제별로 나누어 되돌릴 수 있다. 문제가 있는 수정만 역커밋하되 그 수정으로 막았던 알려진 결함이 다시 나타남을 함께 검토해야 한다. 이전 G01–G08의 저장 형식을 읽는 코드는 유지한다. 전체 저장소를 초기화하는 작업은 롤백에 포함하지 않는다.

## 실기기 검수 범위

합성 회전·기하·특징·시각과 통제된 동시 실행을 이용한 자동 검증은 실제 카메라 정확도나 공간 안전성의 보증이 아니다. LiDAR 아이폰에서 세로 안내 방향, 큰 가구 주변 장애물, 반복 방문, 실제 앵커 갱신과 저장 지속성을 확인해야 한다. Vision 특징의 실제 카메라 버퍼 시험과 기기의 파일 보호 시험, 발열·배터리·메모리 측정도 실기기 검수에 남는다.

기존 기능의 구현과 이전 검증은 [기능 공백 후속 기록](FEATURE_GAPS_2026-09-05.md)을 참조한다.
