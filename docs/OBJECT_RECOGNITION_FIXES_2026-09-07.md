# 물체 인식 및 검색 수정

## 확인한 문제와 변경

| 문제 | 변경 |
| --- | --- |
| 실제 모델 이름과 한국어 사전 불일치 | 모델 파일의 80개 클래스 전체를 `ObjectSemanticCatalog`에 연결했다. `tvmonitor`, `diningtable`, `pottedplant`와 일반적인 영문·한국어 이름을 함께 처리하며 기존 저장 기록을 유지한다. |
| 관측 기록이 없으면 검색어 이해 실패로 안내 | 이름 해석과 저장 기록 조회를 분리했다. 아직 관측하지 않은 지원 종류, 자동 인식 미지원 종류, 물체명 불명확, 제외된 저장 기록을 구분한다. 사전만으로 물체 ID나 좌표를 생성하지 않는다. |
| 띄어쓰기 없는 한국어 검색 실패 | `키보드어디있어?`, `내키보드찾아줘`, `키보드마지막위치알려줘` 등의 완결된 요청 어미를 처리한다. 물체 이름이 다른 명사 일부에 포함된 경우에는 일치시키지 않는다. |
| 영상 비율 왜곡과 과도한 같은 종류 후보 제거 | 영상 방향을 적용한 뒤 비율을 유지해 416×416 입력에 맞추고, 검출 상자를 원래 영상 좌표로 되돌린다. NMS IoU를 0.1에서 0.45로 명시적으로 설정하고 화면 후보 기준을 0.30으로 설정했다. |
| Tiny 모델이 실제 예시의 키보드·마우스를 놓침 | 맥북에서 사용자 제공 사진을 실제 Core ML로 비교한 뒤 Apple 배포 `YOLOv3Int8LUT`로 교체했다. 같은 비율 보존 전처리와 0.30 기준에서 키보드·마우스·모니터가 검출됐다. 모델 크기는 약 8.9 MB에서 62.2 MB로 늘어난다. |
| 검출했지만 3D 저장 조건 미달이면 화면에서도 찾기 어려움 | 최근 검출을 영구 저장과 분리했다. 검색한 물체의 화면 후보에 점선 상자를 표시하고 깊이·지도·분류·위치 확인 중임을 안내한다. 만료되거나 좌표 연결이 무효화된 후보는 표시하지 않는다. |
| 자동 모델 범위 밖 물체를 기억할 수 없음 | 사용자가 물체 표면에 가운데 표시를 맞추고 이름을 붙여 마지막 확인 위치를 등록할 수 있다. 자동 검출 결과나 이동 후 추적으로 표현하지 않는다. |

## 직접 등록

검색 결과의 **이 물체 위치 직접 기억** 또는 하단 메뉴의 **물체 위치 직접 등록**을 사용한다. 가운데 표시를 물체 표면에 맞추고 이름을 입력한 뒤 **현재 위치 기억**을 누른다.

- 실제 raw 깊이의 높은 신뢰도 표본을 서로 다른 프레임에서 3개 이상, 최소 0.3초 동안 확인한다.
- 확정된 지도·좌표계·세션과 정상 추적, 최근 프레임, 안정된 위치가 필요하다. 깊이가 없거나 표면 위치가 불안정하면 저장하지 않는다.
- 측정된 점 중 대표점을 선택한다. 저장 내용은 사용자 이름과 마지막 확인 위치이며, 물체의 크기나 점유 영역을 만들지 않는다.
- `semanticLabel=user_registered_object`, `displayName=사용자 이름`, `presence=lastSeen`, `bounds=nil`로 저장한다. 자동 모델의 종류·재식별 결과로 위장하지 않는다.
- 물체가 이동하면 새 위치를 직접 등록해야 한다. 같은 이름의 기록이 여러 개면 검색 결과에서 기록 시각과 후보를 확인한다.
- 등록 취소·앱 비활성화·공간 전환 시 이전 결과를 표시하지 않는다. 데이터 삭제·가져오기·내보내기 전에 진행 중인 저장 작업을 완료 대기한다.

## 위치 안내의 조건

화면 후보는 이미지 좌표만 가진다. 후보를 찾았다는 이유로 저장된 위치, 물체 동일성, AR 방향 또는 경로를 확정하지 않는다. 기존 자동 저장의 반복 관측·분류 신뢰도·깊이·지도 조건과 경로 안전 검증은 유지한다.

자동 인식 모델은 여전히 COCO 80종이다. 새 전처리와 후보 설정의 실환경 정확도 개선 폭, 작은 물체·어두운 물체의 재현율은 물리 iPhone으로 측정해야 한다. 직접 등록은 미지원 물체의 마지막 위치를 기억하는 기능이며 범용 자동 인식 모델을 추가한 것은 아니다.

## 검증

### 맥북에서 추가로 확인한 모델 한계

사용자가 맥북을 켠 뒤, 제공한 1206×2622 사진을 로컬 맥의 Core ML/Vision에서 비교했다. 개인 사진은 저장소에 포함하거나 외부 추론 서비스로 전송하지 않았다.

| 같은 사진에서의 설정 | 0.30 이상 검출 |
| --- | --- |
| 기존 Tiny 모델 + 비율 보존 전처리 | 모니터 1개 |
| 일반 YOLOv3Int8LUT + 비율 보존 전처리 | 키보드, 마우스, 모니터 3개 |

일반 모델의 점수는 키보드 0.9907, 마우스 0.9907, 모니터 0.8955였으며 `.all`과 `.cpuOnly` 모두 세 물체를 검출했다. 이 값은 모델 출력 점수이며 정확도 백분율이나 물체 동일성의 확률이 아니다. 같은 사진을 겹치는 타일로 나누는 방식은 Tiny 모델의 누락을 해결하지 못해 앱에 추가하지 않았다. 임곗값을 낮추거나 공간 저장 조건을 약화하지 않았다.

동일 입력을 반복한 Mac `.all` 추론 3회는 약 25.8–29.3 ms, CPU 추론은 약 194.2–198.9 ms였다. 동시 빌드와 캐싱의 영향을 받을 수 있는 단일 사진 실험이며, iPhone의 실제 카메라 지연·발열·정확도 측정을 대신하지 않는다. 입력에는 앱 UI가 포함되어 있으므로 실제 ARFrame과도 구분해야 한다.

### 앞선 Windows 검증

- Windows Python 검사: 실제 번들 모델 해시, 416×416 입력, 런타임 임곗값 입력, 80개 클래스와 사전 일치 확인.
- Linux Swift 6.2: 사전·검색·좌표 변환·직접 등록·기존 공간 엔진의 Debug와 Release에서 각각 **380개 테스트 통과**(XCTest 371개 + Swift Testing 9개). 핵심 코드 기준 커밋은 `fed0499`이며 실행 전후 58개 Swift 파일의 SHA-256이 일치했다. 개인 맥북과 기존 Docker 데이터를 사용하지 않는 별도 임시 WSL 환경에서 실행했다.
- iOS용 신규 회귀 테스트: 실제 모델 Vision 입력, 모든 EXIF 방향, 화면 후보 만료, 깊이 부재, 등록 취소·시간 제한·저장 실패 등을 추가했다. Linux의 문법 검사는 Apple 프레임워크 타입 검사나 이 테스트들의 실행을 대신하지 않는다.
- 앞선 GitHub Actions는 결제 실패 또는 사용 한도 문제로 실행 시작 전에 차단됐다. 계정 결제 설정은 변경하지 않았다. 이후 사용자의 맥북 사용 지시에 따라 별도 폴더에서 Xcode 검증을 진행한다.

자동 관측 저널이 이미 있는 지도에 직접 등록한 위치를 추가한 뒤 앱이 재시작되는 경우도 별도 iOS 회귀 테스트로 작성했다. 수동 위치 기록은 검색·내보내기·용량 계산에 유지하되 자동 관측 저널의 초기화·복구 대상에서는 제외한다. 기존 자동 물체의 저널 무결성 검사와 기록 병합은 유지한다. 이 검사는 위 Linux 통과 수치에 포함되지 않으며, 이후 Mac의 전체 iOS 테스트에서 통과했다.

### 완료된 Mac 및 실기기 검증

새 모델을 포함한 Debug·Release 빌드와 archive, 최종 Simulator 테스트 545개, 실제 iPhone 검사 8개가 통과했다. Simulator 전용 제약으로 건너뛴 2개 검사는 실기기에서 통과했다. 서명한 Release 앱을 iPhone에 설치·실행했고, 실제 카메라에서 한국어 키보드 검색이 저장 기록을 찾는 것을 확인했다. 실행 중 확인한 테스트 시간 경쟁 수정과 서명 해결, 증거·한계는 [Mac 및 iPhone 검증 보고서](OBJECT_RECOGNITION_MAC_VERIFICATION_2026-09-07.md)에 정리했다.

물리 기기에서는 다음을 확인한다.

1. 키보드를 비추고 `키보드 어디있어?`를 입력한다. 저장 전에는 후보 상자와 상태, 저장 후에는 기록 기반 결과가 나오는지 확인한다.
2. 모니터·테이블·화분을 한국어와 영어 별칭으로 검색한다. 같은 종류를 여러 개 비췄을 때 후보가 남는지 확인한다.
3. 스피커 등 미지원 종류를 직접 등록하고 앱 재실행 후 이름으로 검색한다. 이동 후 자동으로 위치가 갱신된다고 안내하지 않는지 확인한다.
4. 깊이 부재·추적 불안정·앱 배경 전환·취소·공간 전환·저장 실패·전체 데이터 삭제 시 잘못된 위치나 늦은 결과가 나오는지 확인한다.
5. 다양한 거리·각도·조명에서 전처리 변경 전후 정확도, 지연, 발열을 측정한다.
