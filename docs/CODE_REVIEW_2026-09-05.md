# 2026-09-05 코드 구체화·리팩터링 검토

> 이 문서는 앞선 리팩터링 실행 당시의 기록이다. Mac 연결 복구 이후의 후속 수정·재시험·PR 상태는 [PR 검토 요약](PR_REVIEW_2026-09-05.md)을 따른다. 아래 미완료 표시는 당시 상태를 보존한 것이다.

## 현재 판정

요청된 리팩터링과 아래 결함 수정은 작업 폴더에 반영했다. **최종 변경본의 전체 자동 검증과 실기기 검수는 완료되지 않았다.** 재시험용 소스를 Mac에 전송하는 시점에 연결이 끊겼고, SSH 시간 초과와 Tailscale `Online: false`를 확인했다. 인증·키체인·네트워크 정책은 변경하지 않았다.

98%라는 수치는 측정하거나 보장하지 않는다. 기능별 정상 경로, 정보 부족 처리, 회귀 시험, 실제 방에서의 정확도·성능을 각각 확인해야 한다. 이전 `VERIFICATION_2026-09-05.md`의 564개 통과 기록은 **이 리팩터링 이전 버전**의 결과다.

## 기능별 검증 단위

1. 첫 실행·카메라: 동의 → 권한 → 저장소 보호 → 캡처 시작, 중단·복귀, 권한 거절, 보호 실패 복구.
2. 물체 기억: 반복 인식 → ID·좌표 확정 → 지속 저장, 이동 시 경계 상자 갱신, 재실행·삭제 경계.
3. 검색·관계·마지막 위치: 입력 검증 → 명령 분류 → 저장 근거 조회 → 좌표 확인 → 결과 표시, 오래된 작업 취소.
4. 가구 배치: 후보 → 실제 바닥 포함 → 메시 관측 합집합 → 충돌·문·통로 → 가능/부적합/정보 부족의 구분.
5. 길 안내: 대상 확인 → 지도/현재 위치 시간 검증 → 출발 연결 구간 검증 → 경로 탐색 → 새 근거/취소 시 폐기.
6. 데이터·출시: 백업 제외 → 보호된 읽기/쓰기/격리 → 모든 작업 종료 후 삭제 → 보호된 재생성, 모델 무결성·Release 검증.

각 단위의 실물 조건과 측정 기록은 `DEVICE_ACCEPTANCE.md`를 따른다. 별칭에 이름이 있다는 사실은 모델 인식 지원의 증거가 아니다. 가구 추천은 현재 기하학적 적합성 판단이며, 취향·스타일 자유 대화형 AI를 구현했다고 표현하지 않는다.

## 보안 검토 범위

수정 전 작업 트리를 고정한 Codex Security 스캔은 완료됐다: `bec4f08b-b7d1-4a3f-adb6-8d4a2730c8ee`. 보고 대상은 OS 백업 경계의 낮은 심각도 개인정보 보관 문제 1건(CWE-922). 앱에 원격 업로드·인증·외부 파일 가져오기 경로가 있다고 가정하지 않았다. 백업 활성화 및 백업에 대한 별도 접근이 필요한 조건부 노출이다.

독립 보안 검토는 저장소·보안 역직렬화·센서 버퍼·앱 조립·쿼리·CI/설치 경계를 중심으로 진행했다. 전체 아키텍처 매핑을 모든 소스 행의 보안 감사로 계산하지 않았으며, 보고서의 coverage는 partial이다. 실제 OS 백업 추출, OS 구현, 서명 키, 하드웨어 인식 정확도는 검증하지 않았다. 공통 저장 정책은 구현했지만 최종 집중 시험이 다시 통과하기 전에는 검증 완료로 표시하지 않는다.

스캔 도구 누적 통계: 총 12,522,905 tokens, 캐시 입력 11,745,664, 출력 54,110, 관련 작업 6개. 이는 도구가 반환한 누적 집계이며 이번 후속 수정 구간만의 사용량이나 제품 완성도 지표가 아니다.

## 연결 복구 후 재개 순서

1. Mac을 깨우고 Tailscale/SSH 연결을 읽기 전용으로 확인한다. 사용자 파일은 보존하고 Windows 최신 소스를 검증 복사본에 다시 동기화한다. 실패한 마지막 전송이 적용됐다고 가정하지 않는다.
2. 최종 Swift 서식을 적용하고 다시 동기화한다. 모델 검증, 셸 문법·JSON·프로젝트 설정 검사를 실행한다.
3. 전체 core → 저장소 집중 시험 → 전체 iOS 단위·화면 시험 → Release 무서명 빌드·정적 분석을 직렬 실행한다. 실패를 고치고 관련 시험을 재실행한다.
4. 테스트 수·skip·실패를 결과 번들로 확인하고, 최종 소스 해시와 원격 로그를 보존한다. 현재 문서에 후속 결과를 덧붙인다.
5. 서명된 실기기 설치는 Mac의 정상 사용자 세션에서 수행한다. 키체인 접근 정책을 우회하거나 비밀번호를 요청하지 않는다. 정상·예외 경로의 실물 검수 전에는 98% 또는 출시 완료로 판정하지 않는다.
